这是一个没有数据库、没有后端的静态站点。

## 构成

- **内容**:Markdown 文件,放在 [仓库]({{repo}}) 的 `posts/` 里,用 Obsidian 或任何编辑器写
- **构建**:一个 shell 脚本调用 pandoc,再加一个 perl 预处理和一个 Lua 过滤器处理 Obsidian 的写法
- **托管**:GitHub Pages,推送到 `main` 后由 GitHub Actions 自动构建发布
- **样式**:一个 CSS 文件,没有框架。字体全部使用系统字体,不加载网络字体
- **脚本**:一个约 11 KB(未压缩)的 JavaScript 文件,负责深浅色切换和键盘操作,没有依赖
- **统计与追踪**:没有

## 页脚那行小字

每个页面底部写着构建的提交号、日期、pandoc 版本,以及这一页的体积(HTML、样式、脚本和图片加起来)和请求数。这些数字都是构建时算出来的,不是手写的。

## 键盘

按 `?` 可以看到所有快捷键。按 `:` 会在页面底部打开一行命令行,输入 `help` 查看可用命令。

## 源码

本站所有内容都是公开的:[{{repo}}]({{repo}})。每篇文章底部有"源文件"和"修改历史"的链接,可以看到它从第一版到现在是怎么变化的。
