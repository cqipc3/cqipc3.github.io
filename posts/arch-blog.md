极简博客的核心只有三样东西:Markdown 文件、一个构建脚本,以及一台能托管静态文件的服务器。

## 为什么选择静态

静态页面没有数据库,没有后台进程,也就没有需要维护的攻击面。文章就是文件,用 git 管理,可以随时回到任何一个历史版本。

> 形式服从功能。

构建只需要一行命令:

```bash
pandoc post.md -o post.html
```

## 之后的事

写作才是目的。把时间花在文章上,而不是折腾工具。
